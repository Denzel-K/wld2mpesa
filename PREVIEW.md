# Preview & Local Development on Linux

> ⚠️ Important: Worldcoin does **not** offer a full browser-based simulator for Mini Apps. The only reliable way to test MiniKit commands (pay, verify, wallet auth) is inside the real **World App mobile app**.

The official Worldcoin "simulator" (https://simulator.worldcoin.org) only supports **World ID proof generation**. It does **not** run Mini Apps or handle MiniKit commands.

## How to Test Your Mini App Locally (Fastest / Most Realistic)

### 1) Run your app locally

```bash
# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm run dev
```

Your frontend will be available at **http://localhost:3000**.

> ✅ You can still use the browser to view the UI and debug with DevTools, but **MiniKit commands will not work** (they need the World App webview).

### 2) Expose your local frontend to the internet (required for mobile)

Use a tunneling tool so the mobile World App can reach your local server.

**Ngrok (recommended):**
```bash
ngrok http 3000
```
Copy the generated `https://*.ngrok.io` URL.

Other options: `zrok`, `tunnelmole`, Cloudflare Tunnel, etc.

### 3) Test in the real World App (official method)

1. Open the World App on your phone.
2. Scan a QR code generated by the official Worldcoin QR tool:
   - Go to: **https://docs.world.org/mini-apps/quick-start/testing**
   - Enter your **App ID** (e.g. `app_staging_wld2mpesa`)
   - The page instantly generates a QR code.
3. Scan the QR with your phone camera (or tap the link). Your mini app will open inside World App.

✅ This is the closest experience to a “web-based simulator” and the officially supported testing path.

### 4) Optional: Register your tunnel as your Mini App URL (for repeat testing)

1. Log in to **https://developer.worldcoin.org**
2. Select your App → **Mini Apps / Configuration**
3. Paste your `ngrok` (or deployed) URL as the **Mini App URL**
4. Save

Now any QR/deep link for your App ID will load your local version automatically.

## Debugging on Mobile (recommended)

### Quick mobile console (Eruda)
For faster debugging inside World App, enable an in-app console using **Eruda**.

1. In `frontend/.env.local`, add:
```env
VITE_ENABLE_ERUDA=true
```
2. Reload the app in World App (or refresh via QR).

A small debug overlay will appear with console logs and network inspection.

---

## Tip: Configure required backend environment variables

Ensure `backend/.env` includes the correct World App and payment service keys (World App App ID, Action ID, Yellow Card, M-Pesa, etc.).

1. `npm run dev` (frontend + backend)
2. `ngrok http 3000`
